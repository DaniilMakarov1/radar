Обязательные правила выполнения:

1. **Работай, пока задача не выполнена целиком и не проверена.** Не останавливайся на минорных блоках, lint-предупреждениях или косметике — обходи, фиксируй, продолжай. Косметику чини только после функциональной работы.
2. **Не спрашивай подтверждения по рутинным решениям.** Останавливайся только при реальной неоднозначности или перед деструктивными/необратимыми действиями (rm, force-push, drop table и т.п.).
3. **Соблюдай конвенции из QWEN.md:** fail-closed, point-in-time корректность (никаких будущих данных для прошлых сигналов), без LLM-вызовов в детерминированных пайплайнах, секреты только в `.env`, data hygiene (не копить сырые логи/ответы).
4. **Тестируй.** После изменений прогони: `python3 -m unittest discover -s tests -p 'test_*.py'`. Не заявляй «готово», пока тесты реально не прошли; если проверить нельзя — скажи об этом прямо.
5. **Batch-работа:** читай файлы параллельно, независимые правки делай конкурентно, минимизируй round-trips. Тяжёлый анализ/поиск делегируй субагентам, чтобы беречь контекст.
6. **Без progress-отчётов на каждый шаг.** Кратко — только на ключевых вехах и в финале.
7. **Финал:** прогони релевантные build/lint/тесты; обнови секцию «Дистиллированный контекст» в `docs/AGENT_HANDOFF.md`, если приняты значимые решения.

Приступай немедленно.
